Guessly / Heads Up турдаги шарада (Крокодил) ўйини. Ўзбекча (кирилл ва лотин) ҳамда рус тилида. Битта телефон, бутун оила.

## 1-қадам. APK олиш (GitHub орқали, компьютерда ҳеч нарса ўрнатмасдан)

1. github.com'да янги репозиторий очинг (Private бўлиши мумкин).
2. Шу папкадаги барча файлларни юкланг (`.github` папкаси ҳам бўлсин).
3. **Actions** бўлимида «Android (APK + AAB)» ишга тушади (~6–8 дақиқа).
4. Тугагач, пастдаги **Artifacts** дан `topqir-android-N` ни юклаб олинг — ичида `app-debug.apk`. Уни телефонга ўрнатиб синаб кўринг.

## 2-қадам. Google Play'га жойлаш

**Керак бўлади:** Google Play Console аккаунти (бир марталик тўлов $25).

### 2.1 Имзо калити (keystore) — бир марта яратилади, ЙЎҚОТМАНГ

Java ўрнатилган компьютерда:

```bash
keytool -genkeypair -v -keystore topqir-release.jks -alias topqir \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 topqir-release.jks > keystore.b64     # Windows: certutil -encode topqir-release.jks keystore.b64
```

GitHub → Settings → Secrets and variables → Actions → **New repository secret**:

| Secret | Қиймати |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | `keystore.b64` ичидаги матн |
| `ANDROID_KEYSTORE_PASSWORD` | keystore пароли |
| `ANDROID_KEY_ALIAS` | `topqir` |
| `ANDROID_KEY_PASSWORD` | калит пароли |

Шундан сўнг Actions'ни қайта ишга туширинг — Artifacts'да `app-release.aab` пайдо бўлади. Google Play'га айнан шу **.aab** юкланади.

### 2.2 Play Console'да

1. **Create app** → номи «Топқир», тури Game, Free.
2. **App content**: Privacy policy URL (`privacy.html` ни GitHub Pages ёки сайтингизга қўйинг), Ads — йўқ, Data safety — маълумот йиғилмайди, Content rating анкетаси.
3. **Target audience**: агар 13 ёшгача болаларни ҳам белгиласангиз, «Families» талаблари қўлланади — илова рекламасиз ва маълумот йиғмагани учун мос келади.
4. **Муҳим:** 2023 йил 13 ноябрдан кейин очилган *шахсий* аккаунтлар учун олдин **ёпиқ синов (Closed testing)** шарт: камида **12 тестер, 14 кун** узлуксиз. Оила аъзолари ва танишлар Gmail'ини қўшинг. Ташкилот (юридик шахс) номидан очилган аккаунтга бу талаб қўлланмайди.
5. Синовдан сўнг **Production** → AAB → кўриб чиқишга юбориш (одатда 1–7 кун).

## 3-қадам. App Store'га жойлаш

**Керак бўлади:** Apple Developer Program (йилига $99). Mac шарт эмас — GitHub'нинг macOS сервери йиғиб беради.

1. developer.apple.com → Identifiers → янги App ID: `uz.topqir.app`.
2. **Сертификат** (Apple Distribution). Mac бўлмаса, OpenSSL билан:
   ```bash
   openssl req -new -newkey rsa:2048 -nodes -keyout topqir.key -out topqir.csr -subj "/CN=Topqir/emailAddress=SIZNING@POCHTA"
   # topqir.csr ни Apple'га юкланг, distribution.cer ни юклаб олинг, кейин:
   openssl x509 -inform DER -in distribution.cer -out distribution.pem
   openssl pkcs12 -export -inkey topqir.key -in distribution.pem -out topqir.p12
   ```
3. **Provisioning profile**: App Store Connect туридаги, `uz.topqir.app` учун.
4. **App Store Connect API key** (Users and Access → Integrations) — TestFlight'га автоматик юклаш учун.
5. GitHub Secrets:

| Secret | Қиймати |
|---|---|
| `IOS_CERTIFICATE_P12_BASE64` | `base64 -w0 topqir.p12` |
| `IOS_CERTIFICATE_PASSWORD` | p12 пароли |
| `IOS_PROVISION_PROFILE_BASE64` | `base64 -w0 profile.mobileprovision` |
| `IOS_TEAM_ID` | 10 белгили Team ID |
| `ASC_KEY_ID`, `ASC_ISSUER_ID` | API key маълумотлари |
| `ASC_API_KEY_P8_BASE64` | `base64 -w0 AuthKey_XXXX.p8` |

6. App Store Connect'да янги App яратинг (Bundle ID `uz.topqir.app`), сўнг Actions → «iOS» ни ишга туширинг. Тайёр билд TestFlight'да чиқади → у ердан Review'га юборилади.

> Изоҳ: Apple оддий «веб-сайт ўрами» иловаларни баъзан рад этади (4.2-қоида). Топқирда тебраниш, ҳаракат датчиги, экранни буриш ва офлайн ишлаш бор — бу хавфни камайтиради. Скриншот ва тавсифда ўйин эканини аниқ кўрсатинг. «Guessly» номини ишлатманг.

## Store учун матнлар

**Номи:** Топқир — Сўзни топ! / Топқир — Угадай слово
**Қисқа тавсиф (80 белги):**
- uz: Бутун оила учун шарада ўйини: сўзни пешонага қўй, дўстларинг тушунтиради!
- ru: Шарады для всей семьи: телефон ко лбу, а друзья объясняют слово!

**Тўлиқ тавсиф (uz):**
Топқир — катталар ва болалар бирга ўйнайдиган қизиқарли сўз топиш ўйини. Телефонни пешонангизга қўйинг: экрандаги сўзни ўзингиз кўрмайсиз, жамоадошларингиз эса уни тушунтиради, ҳаракат билан кўрсатади ёки ашула билан ишора қилади. Топдингизми — телефонни пастга эгинг, билмасангиз — тепага.
• 10 та тайёр тўплам: ҳайвонлар, ўзбек таомлари, касблар, Ўзбекистон, болалар учун ва бошқалар
• Ўзбек (кирилл ва лотин) ва рус тилларида
• Жамоалар, ҳисоб ва ғолиб
• Ўз сўз тўпламингизни яратинг
• Интернетсиз ишлайди, рекламасиз

**Полное описание (ru):**
Топқир — весёлая игра в слова для взрослых и детей. Приложите телефон ко лбу: слово на экране видят все, кроме вас. Друзья объясняют его, показывают жестами или напевают. Угадали — наклоните телефон вниз, не знаете — вверх.
• 10 готовых колод: животные, узбекская кухня, профессии, Узбекистан, для детей и другие
• На узбекском (кириллица и латиница) и русском
• Команды, счёт и победитель
• Создавайте свои колоды слов
• Работает без интернета, без рекламы

## Компьютерда синаш (ихтиёрий)

```bash
npm install
npm run build        # шрифтларни www/fonts га кўчиради
npm run serve        # http://localhost:8080
npm run android      # Android Studio'да очиш (Android SDK керак)
npm run ios          # Xcode'да очиш (фақат Mac)
```

Капот остида: Capacitor 7 (Android 6.0+ / iOS 14+).
